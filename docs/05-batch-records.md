## 经验小结

1. **直贴提示词的效果差**（批次 2），需要改写成用户口吻（批次 3 起）。
2. **图文 + 美女题材** 推送效果最佳（批次 4 / 批次 6）。
3. **视频** 单独走 `post_video.py`，详见 [`06-post-video.md`](06-post-video.md)。
4. **批量登录有限流风险**（批次 6 出现 1 个账号触发 429）。
   建议批量登录时账号间间隔 1–2 s；调度器对登录失败的账号自动跳过，剩余账号轮询补足。
5. **PowerShell 5.1 调用 `Invoke-RestMethod` 时需手动把 body 编为 UTF-8 byte 数组**，
   否则中文 + emoji 会被服务端存为 `?`。详见 `scripts/post_moments.py` 的 Python 实现使用 `requests` 已规避此问题；
   PowerShell 复刻版需注意。
